# الاختبار الميداني — ثلاثة مستويات

كل القياسات تُسجَّل بزر **تسجيل CSV** (ملف في مستندات التطبيق، يُشارك بعد الإيقاف).

## المستوى 1 — التكرارية (أهم اختبار)
1. اختر علامة ثابتة واضحة (مسمار في الأرض، زاوية بلاطة).
2. قف فوقها، انتظر «مثبَّت» (وضع سريع) أو ≥60 ث «ثابت» (دقة قصوى)، اضغط **حفظ نقطة**.
3. ابتعد ≥50 م وارجع، كرّر 5 مرات.
4. في **التحليل → النقاط المحفوظة**: «أقصى تشتت» و«RMS» = دقتك الحقيقية.
   **معيار النجاح:** أقصى تشتت ≤ نصف قطر 95% المعروض في معظم النقاط.

## المستوى 2 — النسبي (شريط قياس)
نقطتان على طرفي شريط 50.00 م → «آخر نقطتين». الخطأ المقبول: ≤ 3 م (سريع)، ≤ 1.5 م (دقة قصوى، L5).

## المستوى 3 — المطلق
علامة مساحية معلومة الإحداثيات (WGS‑84). قارن مع DMS في التحليل.

## تحليل CSV
الأعمدة: `time_ms, lat_raw, lon_raw, acc_raw_m, ..., lat_est, lon_est, sigma_m, radius95_m, motion, samples_avg,
rejected, sats_visible, sats_used, l5_used, mean_cn0, session, shown_lat, shown_lon, shown_sigma_m, shown_source, shown_reason`
- `shown_source` = gnss/assist يخبرك متى فاز كل مصدر.
- `shown_reason` = gnssInconsistent يعني انعكاسات (داخل مبنى).
- قارن `acc_raw_m` بـ`shown_sigma_m` لترى مكسب الفلترة.
